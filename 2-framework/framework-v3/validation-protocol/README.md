# Validation material: separate from player use

This folder preserves the earlier 54-competency, 212-level-row assessment draft. Its purpose is to supply possible observation methods for a later pilot. It is a different version from the 46-skill player CSV one folder above. Do not import the coach CSV into the player checklist or treat its statements as extra requirements.

The earlier review's exclusions from global-level grading describe the coach draft, not the player product. The player version retains its levels and five areas. The observation counts and thresholds in this folder are proposals, not validated norms or mandatory player actions.

## Expert review first

Review the CURRENT player CSV, not just the archived coach draft. Freeze a statement-level version before ratings so that scores never silently follow changed wording. Review each separate I-can statement; record its parent row ID and statement index.

Collect independent ratings for relevance, clarity and appropriateness to the proposed level. Use a declared 1–4 scale with criterion-specific anchors (for example, clarity from 1 = unintelligible/major rewrite to 4 = clear without revision). Capture qualitative suggestions, omitted concepts, specialist status and disagreements about ordering. Record expert qualifications and experience with adult recreational players.

For a given statement and criterion, with n valid ratings on a 1–4 scale:

`Aiken's V = sum(rating - 1) / (3 * n)`

Exclude missing responses from n and report the actual n; never turn missing into a score of 1 or 0. No ratings means unavailable. Report confidence intervals using an explicitly selected published method, and declare the revision rule before inspecting the results. Do not attach a generic Valid badge solely because V clears an arbitrary cutoff.

The TTOSP study's twelve experts provide a relevant example, not a universal sample-size requirement. A high V supports expert content agreement. It does not establish the accuracy of a player's self-reported level. No expert scores, V values or confidence intervals have been fabricated here. No admin rating mode has been implemented.

## Field pilot next

Use the archived observation suggestions selectively, after coaches refine their definitions. Collect consented examples of real play, compare self-reports with independent coach judgments, and assess observer agreement. Look for repeated confusion, unstable answers, partner effects and inappropriate level gates. Test whether players can answer the short statements on a phone without coaching terminology.

Test the five-area profile and existing overall-level formula separately. Check missing answers, optional shots, split wings, Mentality behavior interpretation and area weights. A content-valid item bank does not by itself validate the aggregation formula.

The archived two-session observation thresholds need calibration. They should never become a hidden requirement for a recreational player to complete the checklist.
