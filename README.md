# Padel IQ

A personal padel self-assessment, match reflection and coaching app.

| Folder | What's in it |
|---|---|
| `1-brief` | The concept and the original skills brain dump |
| `2-framework` | Skills and shots, coach design and coach rules |
| `4-screens` | Brand assets, mascot, screen notes |
| `5-data` | The data the app reads: skills framework, glossary, quiz, themes |
| `6-app` | The app itself (React + Vite) |

## Run it
```
cd 6-app
npm install
npm run dev
```

## Deploy on Vercel
Import this repository in Vercel and set **Root Directory** to `6-app`. Vercel detects Vite and builds it.

Data is stored in each user's own browser. There are no accounts.
